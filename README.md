# STARTUS tools

STARTUS sports academy の運営・練習支援ツール集。ブラウザだけで動きます。

## ピッチ・ストライド解析

走行動画から区間タイム・平均速度・ピッチ・ストライドを算出するツール。

https://mattun9.github.io/startus-tools/pitch-stride/

- 20m助走 → 10m測定区間 → 減速、の「中間疾走」計測を想定
- ラインの通過は「腰」で判定し、ストライドは 速度÷ピッチ で算出（ライン際の端数歩問題なし）
- 追い撮り（パン撮影）対応／結果の画像保存機能つき
- **動画は端末内で処理され、サーバーには送信されません**

※ 元ファイルの管理は startus-work リポジトリ `tools/ピッチストライド解析.html`。更新したらここへコピーして反映する。

## 議事録アップローダー（クラブ内部用）

録音した会議の音声を送ると、文字起こし・議事録の作成までを自動で行う仕組みへの入口。

https://mattun9.github.io/startus-tools/minutes-uploader/

- 録音は端末標準の録音アプリを使う。このツールは「録れた音声を送る」だけを担当する
- Android では共有シートに「議事録」として表示される（ホーム画面に追加して使う）
- **このツールは音声をクラブのGoogle Driveへ送信します**（上の解析ツールとは異なります）
- 利用にはクラブの送信先URLと合言葉が必要。**知らない人は開いても何も送信できません**

※ 元ファイルの管理は startus-work リポジトリ `tools/minutes-uploader/`。更新したらここへコピーして反映する。
