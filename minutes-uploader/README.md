# 議事録アップローダー

録音した会議の音声を、**共有シートから2〜3タップで**議事録システムに送るための道具。

**録音そのものはスマホ標準の録音アプリ（ボイスメモ等）を使う。**
標準アプリはバックグラウンド録音・電話着信・電池持ちが確実で、自作アプリで勝てないため。
ここが担うのは「録れた音声を送る」ところだけ。

送られた音声は Drive の `00_入力/<会議種別>/` に入り、あとは
[`meetings/apps-script`](../../meetings/apps-script/) の仕組みが自動で議事録にする。

```
録音（標準アプリ）→ 共有 → これ → Drive → 文字起こし → 議事録 → 確認画面 → コミット
```

| 端末 | 使うもの |
|---|---|
| Android | このPWA（共有シートに「議事録」として出る） |
| iPhone | iOSショートカット（下記の手順で5分で作れる） |

---

## 準備（共通）

GASの `setup()` を実行したときにログに出た値を2つ用意する。

- **ウェブアプリURL** … `https://script.google.com/macros/s/..../exec`
- **合言葉** … `PWA_TOKEN` の値

この2つを知っている人だけがアップロードできる。**LINEなどで平文で回さないこと。**

---

## Android（PWA）

### 入れかた

1. Chromeで公開URLを開く
   → `https://mattun9.github.io/startus-tools/minutes-uploader/`
2. 右上メニュー →「**アプリをインストール**」（または「ホーム画面に追加」）
3. 開いて、ウェブアプリURLと合言葉を入れて「保存する」

これで共有シートに「**議事録**」が出るようになる。

### 使いかた

```
録音アプリで停止 → 共有 → 「議事録」 → 会議の種類を選ぶ → 送信する
```

ホーム画面のアイコンから開いて、「ファイルを選ぶ」で送ることもできる。

---

## iPhone（ショートカット）

「ショートカット」アプリで1つ作る。一度作れば共有シートに出る。

### 作りかた

1. **ショートカット** アプリ →「＋」で新規作成
2. 右上の「ⓘ」→ **「共有シートに表示」をオン** → 受け取る種類は「ファイル」「メディア」だけ残す
3. 名前を「**議事録に送る**」にする
4. 以下のアクションを上から順に追加する

| # | アクション | 設定 |
|---|---|---|
| 1 | **メニューから選択** | 項目を2つ：`スタッフMTG` と `指導者ミーティング` |
| 2 | └ スタッフMTGの中 → **変数を設定** | 名前 `種類` ／ 値にテキスト `staff-mtg` |
| 3 | └ 指導者ミーティングの中 → **変数を設定** | 名前 `種類` ／ 値にテキスト `coach-mtg` |
| 4 | **Base64エンコード** | 入力は「**ショートカットの入力**」 |
| 5 | **URLの内容を取得** | 下の表のとおり |
| 6 | **通知を表示** | 「送信しました」 |

**5「URLの内容を取得」の中身**

- URL … ウェブアプリURL
- 方法 … **POST**
- 本文を要求 … **JSON**
- フィールド（すべて「テキスト」型）:

| キー | 値 |
|---|---|
| `token` | 合言葉 |
| `action` | `upload` |
| `type` | 変数「種類」 |
| `filename` | ショートカットの入力の「**名前**」 |
| `mimeType` | `audio/mp4` |
| `data` | 「Base64エンコード」の結果 |

### 使いかた

```
ボイスメモで停止 → 共有 → 「議事録に送る」 → 会議の種類を選ぶ → 完了
```

### iPhoneでの注意

- **60分・25MBくらいまで**が目安。これを超えると Base64 変換でショートカットが固まることがある。
  長い会議は Drive アプリから `00_入力/<会議種別>/` に直接入れるほうが確実。
- ボイスメモの録音品質は「設定 → ボイスメモ → オーディオ品質」で**「圧縮」**にしておく（既定）。
  「ロスレス」にすると数百MBになり送れない。

## うまくいかないとき

| 症状 | 原因・対処 |
|---|---|
| 共有シートに出ない（Android） | 「ホーム画面に追加」ではなく「**アプリをインストール**」を選ぶ。ブックマークでは共有先にならない |
| 「つながりませんでした」 | ウェブアプリURLの末尾が `/exec` か確認。`/dev` では動かない |
| `bad token` | 合言葉が違う。GASの ⚙プロジェクトの設定 → スクリプト プロパティの `PWA_TOKEN` を確認 |
| 送信は成功するが議事録が来ない | GASのトリガーが止まっている。`tick` トリガーを確認 |
| 送ったのに取り込まれない | 音声以外のファイル（メモのテキスト等）を送っている。音声ファイルを選ぶ |

## 公開について

このフォルダが**マスター**。公開は `startus-tools` リポジトリにミラーして GitHub Pages で配信する
（ピッチストライド解析ツールと同じ運用）。

```
startus-work/tools/minutes-uploader/   ← ここを編集する
        ↓ コピー
startus-tools/minutes-uploader/        ← GitHub Pages で公開
        ↓
https://mattun9.github.io/startus-tools/minutes-uploader/
```

**PWAはHTTPSでないと動かない**（Service Worker と共有ターゲットの要件）。
GitHub Pages はHTTPSなので問題ないが、ローカルのファイルを直接開いても共有機能は動かない。

`sw.js` を更新したときは、端末側で一度アプリを閉じて開き直すと新しいものに入れ替わる。
